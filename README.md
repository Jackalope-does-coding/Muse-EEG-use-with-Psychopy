# 2026/04/29 UPDATE

Since many Dawson students are using this code for their final semester projects, I thought I'd upload more useasble versions for analyzing larger sets of participant data.

2 new files have just been added (names preceeded by "UPDATED"), which work the same as the old ones except instead of only analyzing the data for 1 participant, you can add as many participants as you've got. The space to do that is marked in the code and explained at the top of the code. The 2 participant files for each participant should now be added as a tuple, and the results are averaged across all participants at the end so that you can have presentable data for your projects

NOTE: the code was updated using Claude.ai since I am in finals season and don't have the time to update it myself. The averaging has not been tested for accuracy, so I cannot be 100% sure that the way it's being calculated is a perfectly accurate representation of the data, but looks to me like it should work fine. Please let me know if there are any issues by email and I will do my best to update the code accordingly (probably in the summer, but sooner if it is needed). Good luck on all your projects!
